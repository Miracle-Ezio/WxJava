## 关键决策（已与产品方确认）

| 项 | 选型 |
| --- | --- |
| 后端 | Spring Boot + WxJava + MySQL 8 + Redis + 对象存储（COS / OSS） |
| 小程序 | 原生（WXML/WXSS/JS） |
| 管理后台 | Vue 3 + Element Plus |
| 部署 | 云服务器 + 私有桶对象存储 |
| 多门店 / 多租户 | 同时支持（tenant_id + store_id 双隔离） |
| 微信支付 | 一期不接入（仅记账），二期接入 |
| 规划方案呈现 | 结构化表单 + 章节阅读 |
| 基础数据 | 一期演示数据从 PPT 项目（黑金超光子、双生水光、芮艾缇少女枪、童颜针、少女针等）抽取，后期后台维护 |

## 里程碑

- **一期 MVP**（4–6 周）：客户档案 + 照片对比 + 规划方案 + 预约 + 账户 / 等级 + 基础后台
- **二期**（4 周）：微信支付 + 多门店 + 营销
- **三期**：SaaS 化

## 待客户确认事项

详见 PRD 第 8 节，重点：

1. 微信小程序主体资质
2. 是否需要 PDF 导出兼容老顾问习惯
3. 是否接入企业微信
4. 短信通道预算
5. 照片删除策略（软删 vs 硬删）
6. logo 实际品牌色 Hex（UI 风格稿中为占位）

## 下一步建议

文档评审通过后：

1. 设计师按 UI 风格稿出 5 大核心页高保真稿（Figma）
2. 后端按数据库设计跑 MyBatis-Plus 代码生成器，搭建项目骨架
3. 小程序按 PRD 信息架构搭页面骨架 + 联调登录
4. 顾问端"规划方案制作器"作为最早可演示的差异化模块优先开发
