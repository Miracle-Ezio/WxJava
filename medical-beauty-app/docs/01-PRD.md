# 医美客户长期管理小程序 — 产品需求文档（PRD）

> 版本：v0.1（草案）
> 更新日期：2026-05-14
> 状态：待评审

---

## 1. 产品概述

### 1.1 背景
医美机构现有客户档案以一次性 PPT 形式制作（如《彭蕾抗衰整体规划方案》），存在以下问题：
- 单向输出，客户被动接收，无互动；
- 缺乏时间维度，无法跟踪治疗前后变化；
- 项目周期、复购节点全靠顾问人工记忆与微信催办；
- 客户对自己的账户、剩余疗程、消费、等级感知模糊；
- 顾问 / 院长缺乏客户全景视图与数据沉淀。

### 1.2 目标
将「静态 PPT」升级为「动态长期跟踪平台」，让客户从首次到店开始，每一次治疗、每一张照片、每一笔消费、每一个项目周期都形成结构化、可对比、可提醒、可回溯的数字档案。

### 1.3 目标用户
| 角色 | 端 | 核心诉求 |
| --- | --- | --- |
| 客户 | 小程序 | 看自己的变化、知道下次该做什么、自己预约、看账户 |
| 顾问 / 咨询师 | 管理后台 | 制作规划、跟进客户、出业绩 |
| 美容师 / 操作师 | 管理后台（轻量） | 接单、记录操作、上传术后照片 |
| 前台 / 收银 | 管理后台 | 接待、收款、核销、排期 |
| 院长 / 老板 | 管理后台 | 全局数据、业绩、库存 |
| 平台超管（SaaS 阶段） | 管理后台 | 租户管理、计费 |

### 1.4 业务目标（北极星指标）
- 客户**月活 ≥ 60%**（来过即注册）
- 复购周期内**主动到店率 ≥ 70%**（提醒触发后）
- 顾问规划方案**电子化率 100%**（取代 PPT）

## 2. 范围与里程碑

### 2.1 一期（MVP，4–6 周）
- 客户端：登录、个人档案、照片对比、规划方案查看、预约、账户与等级、提醒
- 管理后台：客户 360、规划方案制作器、排期、储值与消费、基础数据维护
- 不接微信支付，**只记账**
- 单门店 / 单租户跑通，但表结构预留 `tenant_id` / `store_id`

### 2.2 二期（4 周）
- 接入微信支付（在线充值、线上购买套餐）
- 多门店上线（跨店预约、跨店核销）
- 订阅消息批量营销、生日营销
- 顾问业绩看板、客户分群

### 2.3 三期（SaaS 化）
- 租户开通流程、计费、域名 / 小程序绑定
- 数据导出 / 接入第三方 ERP
- BI 看板

## 3. 客户端（小程序）功能

### 3.1 信息架构（5 个 Tab，原生 TabBar）

```
首页 ｜ 我的照片 ｜ 预约 ｜ 商城（二期）｜ 我的
```

> 一期可改为 4 Tab：**首页 ｜ 照片对比 ｜ 预约 ｜ 我的**，商城留待二期。

### 3.2 首页
- 顶部：品牌 logo + 当前用户头像 + 等级徽章
- **下一项提醒卡**：「您的童颜水光第 3 次将于 6 月 18 日到期，建议预约 6/15–6/20」 → 一键预约
- **当前规划进度条**：抗衰规划已完成 4/12 步
- 近期照片对比缩略图（首次 vs 最新，自动生成）
- 推荐项目 / 活动 banner（顾问可配）

### 3.3 我的照片（核心模块）
- **拍照引导**：固定 4 个机位（正面 / 左 45° / 右 45° / 顶光），半透明人脸蒙版叠加上一张照片，姿势对齐
- **时间轴**：按月份折叠，缩略图九宫格
- **对比器**：
  - 左右拖拽对比（同机位）
  - 滑块叠加对比
  - 时间跨度筛选（一个月前 / 半年前 / 首次）
  - 单张点开支持局部放大
- **标签**：每张照片可绑定「项目执行记录」（如 6/18 童颜水光第 3 次），点击可跳到该次记录
- **隐私**：照片仅本人 + 授权顾问可见；客户可单独锁定某张；下载 / 截图水印

### 3.4 我的规划（替代 PPT）
按 PPT 同结构呈现，但结构化、可点击、可联动：
- 章节 1：**面部状况分析**（顾问填写：优势 / 劣势 + 标注图）
- 章节 2：**分区规划**（T 区 / 中庭 / 下庭 / 口周 …，每区文字 + 项目）
- 章节 3：**项目清单**（项目名、材料、用量、单价、活动价、周期建议、状态徽章：未开始 / 进行中 / 已完成）
- 章节 4：**抗衰材料 / 仪器科普**（顾问从产品库勾选自动带出说明）
- 章节 5：**套餐报价**（总价、活动价、有效期、签约按钮 — 一期不付款，仅记录意向）

每个项目卡可直接「预约下一次」或「跳到该项目历史照片」。

### 3.5 预约
- 选服务（项目）→ 选门店（多门店）→ 选顾问 / 操作师（可不选）→ 选日期 → 看可用时段（已预约 / 已满）→ 提交
- 提交后状态：**待确认 → 已确认 → 已到店 → 已完成 / 已取消**
- 客户可改期 / 取消（开始前 N 小时，N 后台可配）
- 行程提醒：到店前 24h、2h 推送

### 3.6 我的账户
- **储值卡**：余额、流水（充值 / 消费 / 退款 / 赠送）
- **等级**：当前等级 + 进度条「再充 ¥X 升级到 XX」+ 等级权益清单
- **疗程余量**：每个套餐剩余次数、有效期
- **消费记录**：按时间、按项目筛选
- **优惠券 / 卡券**
- **电子合同 / 知情同意书**

### 3.7 我的（设置）
个人信息、隐私设置（照片授权范围）、订阅消息授权、联系顾问、客服、关于我们

### 3.8 提醒机制
触发源：
1. 项目周期规则（"前 3 个月每月一次，稳定后 2–3 个月一次"配置在项目库）
2. 套餐有效期临近
3. 储值卡余额低
4. 生日 / 纪念日

通道：
- 微信订阅消息（一次性，每次预约后引导授权 1 次）
- 小程序内置消息中心
- 短信（管理后台可选购）

## 4. 管理后台功能

### 4.1 首页看板
今日预约、今日到店、今日营业额、本月新增客户、提醒待办、库存预警、生日客户

### 4.2 客户管理（核心）
- 列表：搜索 / 筛选（等级、阶段、顾问、最近到店、未到店天数）
- 客户 360 详情页：
  - 基础资料（姓名、年龄、肤质、过敏史、紧急联系人）
  - 照片时间轴（同小程序）
  - 抗衰规划（编辑器）
  - 治疗记录时间轴（每次操作：项目 / 材料批号 / 用量 / 操作师 / 备注 / 照片）
  - 财务（储值、消费、欠款、余次）
  - 沟通记录（顾问跟进笔记）
  - 标签（自定义：黄金客户、敏感肌、术后修复中…）

### 4.3 规划方案制作器
- 模板（年度抗衰 / 皮肤管理 / 面雕 …）
- 拖拽章节、引用产品库一键带出说明
- 项目自动生成执行日历
- 一键推送到客户小程序
- 历史版本留档

### 4.4 排期 / 预约管理
- 日历视图（按门店、按顾问、按设备 / 房间）
- 拖拽改时间、批量审核
- 自助预约审核队列

### 4.5 项目 / 产品 / 套餐 / 仪器库
- 项目（黑金超光子、童颜水光 …）：名称、分类、单价、时长、所需仪器、所需材料、周期规则
- 产品 / 材料（伊妍仕、艾维岚 …）：批号管理、库存、临期预警
- 套餐：组合项目 + 次数 + 有效期 + 价格
- 仪器：占用日历，避免冲突

### 4.6 财务
- 储值充值 / 退款（一期手工录入）
- 消费核销
- 日 / 月 / 年报表
- 按顾问 / 项目 / 客户维度业绩

### 4.7 等级体系配置
等级阈值、权益（折扣 / 赠次 / 优先权）、晋级降级规则

### 4.8 员工 / 权限
角色（超管 / 院长 / 顾问 / 操作师 / 前台）+ 数据范围（仅本人客户 / 全店 / 全租户）+ 操作权限矩阵

### 4.9 营销
活动、优惠券、生日营销、批量订阅消息、推荐有礼

### 4.10 系统
门店、租户（SaaS）、字典、操作日志、登录日志、订阅消息模板

## 5. 非功能需求

### 5.1 性能
- 小程序首屏 ≤ 1.5s（含登录）
- 列表接口 P95 ≤ 300ms
- 照片缩略图首屏 6 张，懒加载，COS CDN + WebP

### 5.2 安全 / 合规
- 客户照片：私有桶 + 临时签名 URL（5 分钟过期）+ 客户端水印
- 敏感字段（手机号、身份证、病史）DB 层 AES 加密
- 操作日志全留痕（谁、何时、改了什么）
- 知情同意书电子签 + 时间戳（合规：医美属医疗行为，强烈建议线下纸质 + 线上电子双份）
- HTTPS 全链路、JWT + 短期有效 + Refresh Token

### 5.3 可用性
- 后端 SLA 99.5%
- 数据库每日自动备份，异地保留 30 天
- 照片对象存储跨地域复制

### 5.4 扩展性
- `tenant_id` 全表埋点，索引前置位
- `store_id` 同上
- 项目周期规则用 JSON 表达，避免后期改表

## 6. 用户故事示例

**US-01**（客户）
> 作为一个 55 岁刚做完童颜水光的客户，我希望打开小程序就能看到 6 个月前的自己和现在的对比照，并且系统告诉我下一次该做什么，让我对自己的投入有感知。

**US-02**（顾问）
> 作为顾问，我希望 30 分钟内为新客户出一份带数据、带图、带周期的抗衰规划，并推送到她的小程序，让她回家也能反复看，而不是临走前发个 PPT 给她。

**US-03**（院长）
> 作为院长，我希望每天早上打开后台就能看到今天预约多少人、谁是大客户、本月业绩、哪些客户 60 天没到店该唤醒。

**US-04**（前台）
> 作为前台，我希望客户到店扫码即可调出今天要做的项目、剩余疗程、过敏史，避免问错。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 医美照片合规风险 | 高 | 私有存储 + 签名 URL + 水印 + 客户授权弹窗 + 一键删除 |
| 顾问抗拒电子化 | 高 | 制作器尽量比 PPT 还快；首期保留 PDF 导出 |
| 提醒被关 | 中 | 每次预约都重新引导订阅消息授权 |
| 多租户后期改造痛苦 | 高 | 一期就埋 tenant_id + store_id |
| 微信小程序审核（医疗类目） | 高 | 一期定位为「会员管理」类目，不出现术中术后效果对比的公开展示；客户私密照片 OK |
