# UI 风格稿 / 设计规范

> 版本：v0.1（草案）
> 适配：微信小程序（rpx 单位） + 管理后台（Web，px）
> 设计调性关键词：**轻医美 · 高级 · 干净 · 柔和 · 可信赖**

---

## 1. 品牌色（基于真实 STARRY logo）

### 1.1 品牌识别

> **STARRY · 思达芮**
> "天空中闪耀的繁星 · THE STARS SHINING IN THE SKY"
> Logo：极简黑白衬线，S 与 R 字母艺术化交叠，下方"STARRY"全大写衬线 + "思达芮"中文宋体

品牌调性：**极简、高奢、星空、安静、留白**。视觉策略走 **monochrome + 微弱星空感金色点缀**，避免一切廉价感。

### 1.2 主色板

```css
/* ─── 品牌主色：纯黑白 ─── */
--brand-ink:        #0A0A0A;   /* 主色：墨黑（不用 #000，更柔） */
--brand-ink-soft:   #2A2A2A;   /* 次黑：长文本 */
--brand-paper:      #FFFFFF;   /* 主背景：纯白 */
--brand-paper-warm: #FAF9F6;   /* 次背景：暖白纸感 */

/* ─── 点缀：星辰金 + 夜空蓝 ─── */
/*   来自 slogan「天空中闪耀的繁星」                              */
/*   只在 CTA / 等级徽章 / 重要状态使用，绝不大面积铺          */
--accent-gold:      #C8A96A;   /* 星辰金 — 等级、徽章、关键 CTA */
--accent-gold-soft: #E8DCC2;   /* 浅金 — 选中态、tag 底色 */
--accent-night:     #1B2541;   /* 夜空蓝 — 仅用于黑卡 / 高级别 */

/* ─── 中性灰阶 ─── */
--neutral-900: #0A0A0A;
--neutral-800: #2A2A2A;
--neutral-700: #4A4A4A;   /* 正文 */
--neutral-500: #8A8A8A;   /* 次要文字 */
--neutral-300: #D8D8D8;   /* 边框 */
--neutral-200: #ECECEC;   /* 分隔线 */
--neutral-100: #F5F5F5;   /* 浅背景 */
--neutral-50:  #FAFAFA;   /* 页面底 */

/* ─── 功能色（低饱和，与品牌调性一致） ─── */
--success: #5B8A6F;
--warning: #C89A4A;
--danger:  #B05656;
--info:    #5A7088;

/* ─── 等级体系（呼应"星辰"） ─── */
--level-stardust: #B0B0B0;   /* 星尘 — 普通 */
--level-silver:   #C8C8C8;   /* 银河 — 银卡 */
--level-gold:     #C8A96A;   /* 星辰 — 金卡 */
--level-night:    #1B2541;   /* 夜空 — 黑卡 */
--level-nova:     #6F8FB5;   /* 新星 — 钻石 */
```

### 1.3 渐变（克制使用）

```css
/* CTA 按钮 / 等级徽章 */
--gradient-ink:    linear-gradient(135deg, #2A2A2A 0%, #0A0A0A 100%);
--gradient-gold:   linear-gradient(135deg, #D8BC82 0%, #B8995A 100%);
--gradient-night:  linear-gradient(135deg, #2C3A5F 0%, #1B2541 100%);

/* 卡片背景（仅"下一项提醒"等关键卡用） */
--gradient-paper:  radial-gradient(circle at 20% 0%, #FFFFFF 0%, #FAF9F6 100%);
--gradient-starry: linear-gradient(180deg, #FAF9F6 0%, #F0EBE0 100%);
```

### 1.4 用色铁律

- **页面主背景永远是白或暖白**，禁止整页深色
- **黑色是主色，金色只作点缀**（CTA、徽章、价格强调、装饰线），单屏金色面积 ≤ 5%
- **夜空蓝仅用于黑卡客户的等级标识 / 高端套餐 banner**，不出现在普通客户视图
- logo 在小程序内：白底页显示黑色版，深色 banner 显示白色版

## 2. 字体

### 2.1 字体族
- **中文**：苹方（iOS / 微信内置）/ HarmonyOS Sans（Android）
- **英文 / 数字**：DIN Alternate（数字标题）/ SF Pro / Inter
- 系统降级链：`PingFang SC, Helvetica Neue, Helvetica, Arial, "Hiragino Sans GB", "Microsoft YaHei", sans-serif`

### 2.2 字号体系（小程序 rpx，1 rpx ≈ 0.5px @ 750 设计稿）

| 用途 | rpx | px（参考） | 字重 | 行高 |
| --- | --- | --- | --- | --- |
| 大标题 H1 | 48 | 24 | 600 | 1.4 |
| 标题 H2 | 36 | 18 | 600 | 1.5 |
| 小标题 H3 | 32 | 16 | 500 | 1.5 |
| 正文 | 28 | 14 | 400 | 1.6 |
| 辅助 | 24 | 12 | 400 | 1.5 |
| 标签 | 22 | 11 | 500 | 1.4 |
| 数字（金额、次数） | 56 | 28 | DIN-Bold | 1.2 |

**金额 / 数字单独用 DIN 字体**，是医美高级感的关键细节。

## 3. 间距与圆角

```
spacing: 8 / 16 / 24 / 32 / 48 / 64 rpx
```

- 圆角：
  - 卡片：**16 rpx**（柔和）
  - 按钮：**44 rpx**（药丸状，胶囊按钮，更现代）
  - 头像：圆形
  - Tag / 徽章：完全圆角
- 阴影（一律柔和、低饱和）：
  ```
  --shadow-card:  0 4rpx 16rpx rgba(184, 149, 106, 0.08);
  --shadow-float: 0 8rpx 32rpx rgba(31, 27, 22, 0.12);
  ```

## 4. 关键组件视觉规范

### 4.1 按钮

| 类型 | 背景 | 文字 | 用途 |
| --- | --- | --- | --- |
| Primary | `--gradient-brand` | white | 主操作（预约、确认、保存） |
| Secondary | white + 1rpx border `--brand-primary` | `--brand-primary` | 次要操作 |
| Ghost | transparent | `--neutral-700` | 取消、关闭 |
| Danger | `--danger` | white | 删除、强提示 |

高度统一 **88 rpx**；内边距 **0 48rpx**；点击态降 8% 亮度。

### 4.2 卡片
- 默认 `background: white; border-radius: 16rpx; box-shadow: --shadow-card;`
- 重要信息卡（如等级、下一项提醒）用 `--gradient-glow` 渐变底 + 墨黑 / 星辰金描边

### 4.3 输入框
- 单行高 88rpx，圆角 12rpx，1rpx 浅边框，聚焦时变 `--brand-primary`
- Label 在上方而非占位符里（避免输入后丢失上下文）

### 4.4 标签 / 徽章
- 文字 22rpx，padding 4rpx 16rpx，圆角 999rpx
- 等级徽章：渐变背景 + 白字 + 小图标，与 `level_config.icon_url` 联动

### 4.5 头像
- 客户：56 / 80 / 120 rpx 三档
- 等级角标：右下角小贴章

### 5.2 照片对比
- 进入：时间轴（按月）+ 顶部"对比"按钮
- 对比模式：上下滑动选时间点 A / B，左右拖拽分隔线（核心功能）
- 隐私 banner 常驻底部："您的照片仅您与顾问 沈妍希 可见"

### 5.3 我的规划（取代 PPT）
- 顶部封面图 + 标题 + 顾问头像 + 有效期
- 章节锚点导航（吸顶）：状况分析 / T 区 / 中庭 / 下庭 / 套餐
- 每个项目卡：项目图、名称、已完成 X/Y 次、周期建议（小字）、CTA「预约」
- 底部："导出 PDF" + "联系顾问"

### 5.4 预约
- 步骤条 1-2-3-4
- 日历：横向滑动 14 天，墨黑 / 星辰金底标记可约日
- 时段：宫格，灰=已满，描边=可选，实心=已选
- 提交后过渡到"已提交，等待门店确认"页

### 5.5 我的账户
- 顶部储值卡（横版，墨黑 / 星辰金渐变 + 金色烫印感数字 + 等级徽章）
- 余额 + 累计充值进度条「再充 ¥2,000 升级金卡」
- 二级入口：消费记录、疗程余量、卡券、电子合同

## 6. 管理后台视觉

- 整体风格：**Element Plus** 默认布局 + 品牌色覆盖
- 主色覆盖：`--el-color-primary: #B8956A;`
- 侧栏：白底 + 墨黑 / 星辰金图标 + 选中态浅色背景（不要深色侧栏，太重）
- 客户 360 页面用三栏布局：左栏客户基础信息常驻、中栏时间轴、右栏快捷操作
- 关键数据表用浅色斑马纹 `#FAFAF8`，避免黑底感
- 图表：ECharts，主色统一品牌色，辅色用 `--info / --success / --warning`

---

## 7. 图标 / 插画

- **图标库**：iconfont 自建一套（或基于 Tabler Icons / Phosphor 二次描色）
- **线性图标**：1.5 rpx 描边，圆角端点
- **插画**：空状态、引导拍照、引导授权订阅消息用统一插画师风格（推荐 Iconscout / Storyset 风格，米色 + 墨黑 / 星辰金配色）
- **拍照引导**：半透明白色蒙版 + 墨黑 / 星辰金人脸轮廓线

---

## 8. 暗黑模式
**一期不做**。医美客户拍照核心场景需要稳定的明亮背景做色彩判断，强行做 dark mode 会降低专业感。

---

## 9. 无障碍
- 正文与背景对比度 ≥ 4.5:1
- 主色 `#B8956A` 在白底上对比度 3.5（接近 AA 大字标准），用于按钮 OK；用于正文文字时需加深到 `#8B6A3F`（提供 `--brand-primary-text` 备用）
- 所有可点击元素最小热区 88×88 rpx

## 11. 风格"不要做"清单（避免廉价感）

- ❌ 不用饱和度过高的粉、紫、玫红
- ❌ 不用 emoji 装饰 UI
- ❌ 不用毛玻璃过度（仅用于头部沉浸式 banner）
- ❌ 不用纯黑 #000，统一用 `--neutral-900`
- ❌ 不用阿里普惠体（被滥用），改用苹方
- ❌ 不要满屏渐变，渐变只用在 CTA 和重要卡片
- ❌ 不要"诊所风"的医蓝（让客户联想到打针 / 医院）
