# STARRY · 思达芮 内部版部署手册（体验版路线）

> 只给授权用户使用，**不提交微信审核 / 不公开搜索**，用体验版机制发放。
> 从零到甲方能用，**3–7 天**（主要等 ICP 备案）。

---

## 总览：您能砍掉的事

跟公开版比，走内部体验版：

| 项 | 公开版 | 体验版（本手册） |
|---|---|---|
| 微信小程序审核 | 3–15 天 | ❌ **完全跳过** |
| 医美 / 美容类目区分 | 要选对 | ❌ 随便选个宽松类目 |
| 数据脱敏（V7 迁移） | 必须 | 可选（内部用可保留真项目名） |
| 项目名（黑金超光子/童颜针等） | 要脱敏 | ✅ **直接用真名** |
| 微信支付商户号 | 视情况 | ❌ **不接** |
| 隐私协议 / 用户协议 | 要挂 | 建议挂，非强制 |
| 全球公开可搜 | 是 | ❌ 只有 100 个体验成员能进 |

**首年成本 ~2800 元，比公开版省 2000 元 + 4 周时间。**

## 阶段 1：小程序注册（1–3 天）

### 1.1 小程序申请

mp.weixin.qq.com → 注册小程序 → 用**北京思达芮医疗美容诊所有限公司**营业执照

**类目选** ✅：

| 优先级 | 类目 | 理由 |
|---|---|---|
| ⭐ 首选 | 工具 → 效率 | 最宽松、审核最快、后期最灵活 |
| 备选 | 生活服务 → 美容美发 | 也可以，类目名符合甲方业务 |
| ❌ 别选 | 医疗 → 医美 | 要医疗执业许可证、审核最严 |

**为什么可以随便选**：体验版不会因为"类目 vs 实际内容不符"被下架，微信只在**转正式版提审时**才校验，您不打算转就没事。

审核 1–3 天后拿到 **AppID + AppSecret**。

### 1.2 无需在线支付
所有费用在门店现场收，不申请微信支付商户号。

### 1.3 订阅消息模板（可选，但推荐）
即使体验版也能发订阅消息，客户能收到到店提醒。申请 4 个模板即可（见 DEPLOY.md 1.4 节）。

**注意**：即使是体验版，订阅消息**要在小程序里申请通过后才能用**，需要 1-3 天。可以晚点做，不阻塞上线。

## 阶段 2：域名 + 备案（5–20 天，唯一等的事）

**这一步省不掉**——小程序强制要求 HTTPS 合法域名，合法域名必须备案。

- 买域名（阿里云 / 腾讯云）：50 元/年
- 提交企业 ICP 备案，5–20 天

> 想跳过备案？服务器放**香港 / 境外**也行，域名不需备案。但国内客户访问慢，且部分省市网络不稳定，不推荐。

## 阶段 3：服务器部署（1 天）

跟原 DEPLOY.md 阶段 3 一样，一字不改照抄即可：

1. 云服务器 ECS 2核4G（~150 元/月）
2. Docker + Docker Compose 装好
3. `git clone` 代码
4. 改 `docker-compose.prod.yml` 里 7 处占位：
   - `WX_MA_APPID` / `WX_MA_SECRET`（真实小程序凭据）
   - `JWT_SECRET`（32 字节随机串）
   - `DB_PASSWORD`（强密码）
   - `COS_*`（腾讯云 COS 凭据，可选，不上传照片时留空）
5. `docker compose -f docker-compose.prod.yml up -d --build`
6. nginx + certbot 加 HTTPS（`api.starry-mb.com`、`admin.starry-mb.com`）

详见 `DEPLOY.md` 阶段 3。

## 阶段 4：转体验版 + 邀请体验成员（10 分钟）

### 4.1 小程序改配置

`miniapp/app.js`：
```js
globalData: {
  mockMode: false,                              // ⚠ 关掉演示
  apiBase: 'https://api.starry-mb.com',         // 真实后端
}
```

`miniapp/project.config.json`：
```json
"appid": "wx你的真实小程序AppID"
```

### 4.2 上传代码

微信开发者工具 → 右上角 **"上传"** → 填版本号（如 `1.0.0`）+ 描述 → 上传完成。

### 4.3 转为体验版

mp.weixin.qq.com → **版本管理** → 找到刚上传的版本 → 点 **"选为体验版"**

**不要点"提交审核"**——那是往正式版走的。

### 4.4 添加体验成员（这是关键）

mp.weixin.qq.com → **成员管理** → **体验成员** → **绑定微信号**（填对方微信号 / 微信手机号）

- 默认上限 **100 人**
- 满了在同一页面**申请扩容**（微信客服 1-3 天审）

### 4.5 发给授权用户

体验成员的手机微信里：
- **发现 → 小程序**里搜您的小程序名，进入时会显示"体验版"红条
- 或者直接扫小程序码

您可以在 **版本管理 → 体验版** 里生成体验版二维码，微信截图发给客户。

## 更新代码流程（日常）

您代码改了：

**后端**：
```bash
ssh root@服务器IP
cd /opt/WxJava
git pull
cd medical-beauty-app
docker compose -f docker-compose.prod.yml up -d --build server
```

**小程序**：
- 开发者工具"上传" → 生成新版本号
- 公众平台 → 版本管理 → **把新版本"选为体验版"**（会替换旧的）
- 体验成员**下次打开会自动更新**（不用重新加成员）

**管理后台 Web**：
- 本机 `npm run build`
- `scp -r dist/* root@服务器IP:/var/www/admin/`

5. 走一遍 V7 数据脱敏（如果之前用真项目名）
