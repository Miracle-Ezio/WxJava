# STARRY Mini-Program

微信原生小程序客户端。

## 🚀 快速预览（无需后端，5 分钟）

这是最快的看 demo 方式，**不用起 MySQL、不用部署后端、不用真实 AppID**。

### 1. 下载并安装"微信开发者工具"
- 官方下载：搜 "微信开发者工具" → 下载稳定版 (Stable)
- macOS / Windows 都支持
- 用您的个人微信扫码登录工具

### 2. 打开本项目
在开发者工具里 **+ 新建项目**：
- **项目名称**：STARRY 思达芮
- **目录**：选 `medical-beauty-app/miniapp/` 这个目录
- **AppID**：点 **"测试号"** 即可（无需注册）
- **不使用云服务**：勾选
- 点 **新建**

### 3. 配置项目细节
首次打开后，工具左上「详情」→「本地设置」勾选：
- ☑ **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
  （用于加载演示头像 picsum.photos）
- ☑ 将 JS 编译成 ES5（可选）

### 4. 开始预览
工具左侧菜单选「模拟器」（默认就是），右上角"编译"，立刻能看到：
- **登录页**：点"微信一键登录（演示）" → 进入主页
- **首页**：欢迎彭蕾 + 下一项提醒卡 + 我的规划
- **照片对比 Tab**：四个时间点的演示照片 + 同机位首张 vs 最新对比卡
- **预约 Tab**：未来一次双生水光预约 + 历史治疗记录
- **我的 Tab**：金卡等级徽章

### 5. 完整体验路径
建议按以下顺序点一遍：
1. 登录 → 首页看下一项提醒
2. 点首页"立即预约" → 完整走完 4 步预约向导
3. 切到「对比」Tab → 点快捷对比卡 → 滑动 / 并排两种模式
4. 长按时间轴某张照片 → "作为对比 A" → 再长按另一张 → "作为对比 B"
5. 点右上"+ 拍照" → 体验拍照引导（实际拍照在模拟器里可能受限，可点"相册"测试上传交互）
6. 首页"我的规划" → 进规划详情 → 拉到底看项目卡 → 点项目名跳预约

> 演示数据完全照《彭蕾抗衰整体规划方案》PPT 还原，您可以直接拿给客户/同事看效果。

## 🔧 切到真实后端

演示完想接真后端时：

1. **后端要起来**：参考 `../server/README.md` 配 MySQL + Redis + 微信 AppID 后 `mvn spring-boot:run`
2. **照片要能上传**：还得配腾讯云 COS（不配也能跑，只是上传会报错）
3. **小程序改两处**：
   - `app.js` 把 `mockMode: true` 改成 `false`
   - `app.js` 把 `apiBase` 改成真实后端域名（小程序要求 HTTPS，开发期可在详情里勾"不校验合法域名"）
4. **真实小程序 AppID**：`project.config.json` 的 `appid` 改成在 mp.weixin.qq.com 申请的小程序 AppID（医疗类目需要"北京思达芮医疗美容诊所有限公司"主体）

## 设计要点

- **风格**：纯白 / 暖白底 + 极简黑色衬线 logo + 星辰金点缀（呼应 STARRY · 思达芮"天空中闪耀的繁星"调性）。
- **登录态**：JWT 写入 `wx.setStorageSync`，`onShow` 中守门 `app.isLoggedIn()`。
- **请求**：`utils/request.js` 自动注入 `Authorization`；遇 401 自动重新登录；mockMode 时由 `utils/mock.js` 拦截，零后端依赖。
- **页面切换**：tabBar 4 个 Tab + 内部 `wx.navigateTo` 进规划详情。
- **规划详情页**：复刻 PPT 章节结构（分析 / 分区规划 / 项目建议 / 材料 / 套餐报价），但每项可状态化 / 可点击 / 可联动预约。
